# Lastborn Creative

Official website for **Lastborn Creative**, a video editing and content creation studio serving YouTubers, churches, businesses, and brands.

**Live site:** [(https://lastborntalks.github.io/Lastborn-Creative/)](https://lastborntalks.github.io/Lastborn-Creative/)

## About

Lastborn Creative turns raw footage into polished, engaging videos, from long-form YouTube edits and short-form social content to church event coverage and business advertisements. This repo contains the source for the studio's portfolio and contact website.

## Tech

Plain HTML, CSS, and JavaScript. No frameworks, no build step, no dependencies.

```
docs/
├── index.html   # page structure
├── style.css    # all styling
└── script.js    # portfolio filtering, FAQ accordion, form logic, etc.
```

## Running locally

No install needed. Clone the repo and open `docs/index.html` directly in a browser, or serve the `docs` folder with any static server.
